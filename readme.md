App para aprender as bandeiras dos países

Funcionamento geral:
É um jogo, aparece a bandeira e vc precisa identificar o país (de uma lista de países)
No Seterra, primeiro aparece o país e vc precisa identificar a bandeira (achar a bandeira no meio de um mte)

MVP: bandeiras da américa do sul
Aparece a bandeira, vai aparecer uma lista de países, e aí escolhe a bandeira.
Se marcar que quer ver a info, aparece a info
