
# Bandeiras

Game para aprender as bandeiras dos países

Game baseado no Seterra, com o adicional de ter uma explicação para contextualizar a simbologia das bandeiras.

**Engine principal:**

Dado o nome do país, selecionar a bandeira correta entre as que estão no display.

**MVP:**
- GUI básica
- Bandeiras da América do Sul com suas imagens e info
- Banco de dados com as informações de bandeiras e questões

**Desenvolvimento:**
- Desenvolver ideias iniciais em Java OK
- Fazer o MVP em React
- Migrar para ReactNative

## Como rodar

Pré-requisitos: Node.js >= 18 e npm >= 10

### Instalar dependências

```bash
npm install
```

### Rodar em modo desenvolvimento

```bash
# Todos os apps/packages
npm run dev

# Apenas o app web
npm run dev:web
```

O app web (Next.js) vai subir em http://localhost:3000

### Build de produção

```bash
npm run build
```

### Testes

```bash
npm run test
```
